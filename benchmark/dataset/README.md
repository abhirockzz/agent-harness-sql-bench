# Tasks

These five task folders come from [HiL-Bench SQL](https://hub.harborframework.com/datasets/scale-ai/hil-bench-sql-ask-human) by Scale AI. The gaps with their answers (`blockers.json`) and the answer keys (`ground_truth.sql`, `golden_output.csv`) are copied unchanged. `prompt.txt` holds HiL-Bench's question with its opening line, without Harbor's command-line instructions, and `task.json` records the HiL-Bench task number, the database and the pinned Docker image the data comes from.
