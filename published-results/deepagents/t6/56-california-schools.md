The schools table has no separate district-status column, so I used the school's StatusType = 1 (Active) as the active filter.

```sql
SELECT s.School, s.Phone, s.OpenDate, sat.AvgScrRead
FROM schools s
JOIN satscores sat ON s.CDSCode = sat.cds
WHERE s.StatusType = 1
  AND s.OpenDate BETWEEN '2000-01-01' AND '2004-12-31'
  AND sat.AvgScrRead IS NOT NULL
ORDER BY sat.AvgScrRead ASC
LIMIT 5;
```
